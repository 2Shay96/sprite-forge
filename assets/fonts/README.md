# Supplied 0.7 fonts

The build embeds ShareTechMono-Regular.ttf and the three BarlowCondensed-Preview-*.woff files through src/fonts.css. The WOFF files were decoded byte for byte from the authoritative supplied 0.7 preview; they are not conversions of the existing TTF files. The Share Tech Mono bytes exactly match the existing local TTF. Font families, weights, formats and display policy retain the supplied CSS declarations.
