04 / VIEWS
Directions
All views share the selected animation’s frame timing.
Approximations squash, mirror and darken the front artwork. They do not reconstruct hidden sides. Mirroring also reverses text and asymmetry.
Which mode?
Approximations create eight stylised variations. Reuse one source view shows the same artwork at every angle. Import real directions when you have matching artwork. Source faces Left/Right overrides this in Encounter to mirror the source toward its target.
New projects start with approximations. Source Packs contain up to eight views, so export takes longer and uses more space. Saved projects keep their chosen mode.
